# Alumni Management System using Flask and SQL

This project is a web-based **Alumni Management System** developed using the Flask framework and SQL database. It enables colleges and educational institutions to store, manage, and track alumni information efficiently while maintaining strong communication between alumni and the institution.

The system provides secure login, alumni registration, event management, and interactive communication features.

---

## 🚀 Features
- Alumni Registration & Login
- Secure Admin Dashboard
- Alumni Profile Management
- Batch-wise / Department-wise Alumni Directory
- Job & Internship Sharing
- Event Updates / Notifications
- Search & Filter Alumni Database
- SQL Database Storage

---

## 🧠 Tech Stack
| Category | Technology |
|----------|------------|
| Framework | Flask (Python) |
| Backend | Python |
| Frontend | HTML, CSS, JavaScript |
| Database | MySQL / SQL Connector |
| Authentication | Flask-Login / Session-based |
